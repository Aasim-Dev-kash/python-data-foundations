# Python Programming & Data Foundations (Semester 1)

## 1. Purpose
This repository documents my foundational coursework, problem-solving scripts, and initial data exploration exercises during Semester 1 of my B.Tech in Computer Science and Engineering (Data Science & Machine Learning) at Lovely Professional University (LPU).

## 2. Tools & Technologies
* **Language:** Python 3
* **Libraries:** `pandas`, `matplotlib`
* **Environment:** VS Code, Jupyter Notebook, Google Colab, Ubuntu Linux / Windows

## 3. Implementation
* Core Python scripts covering control flow, functions, data structures (lists, dictionaries, tuples), and file handling (`INT108`).
* Exploratory Data Analysis (EDA) notebooks demonstrating basic data cleaning, tabular manipulation with `pandas`, and chart plotting with `matplotlib`.
